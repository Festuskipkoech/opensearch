Redis persistence: RDB and AOF
Redis supports two primary persistence mechanisms. RDB snapshots the dataset at specified intervals while AOF logs every write operation. Each carries distinct durability and performance tradeoffs depending on your use case.

RDB vs AOF — when to use each
RDB gives compact snapshots and faster restarts. AOF offers better durability with fsync-per-second or fsync-always modes. Most production deployments run both simultaneously.
